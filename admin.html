Journal editor

Connect to your journal’s GitHub repo

  1. Open GitHub’s new token page.
  2. Name it (e.g. “journal editor”) and set an expiration — up to a year.
  3. Under Repository access, choose Only select repositories and pick the journal repo.
  4. Under Permissions, set Contents to Read and write, and Pages to Read-only.
  5. Click Generate token, copy it, and paste it below.

The token is saved only in this browser on this computer.
